# Sprint 1 Retrospective

**Project:** Board Game Community System  

---

## สรุปผลการ Retrospective

### 1. Start (สิ่งที่ควเริ่มทำใน Sprint 2)
* **กำหนดขอบเขตงานให้ชัดเจน:** ตกลง Scope ของ User Story แต่ละตัวให้แน่ชัดก่อนเริ่มเขียนโค้ด เพื่อป้องกันปัญหาการปรับเปลี่ยนข้อกำหนดระหว่างทาง
* **เขียน Unit Test:** เพิ่มการเขียน Unit Test ควบคู่กับการพัฒนา เพื่อรักษาสภาพแวดล้อมให้ปลอดภัยและลดข้อผิดพลาดจากการทำ Refactoring (Zero Regressions)
* **ใช้ GitHub Milestone:** กำหนด Milestone สำหรับ Sprint 2 และผูก Issues ทุกอย่างเข้ากับ Milestone เพื่อติดตามภาพรวมการส่งมอบงานได้แม่นยำยิ่งขึ้น

---

### 2. Stop (สิ่งที่ควรเลิกทำ)
* **หยุดเอางานมาทำใกล้เดดไลน์ (Procrastination):** กระจายการพัฒนางานอย่างสม่ำเสมอตลอดระยะเวลา Sprint เพื่อลดความเครียด ความผิดพลาด และมีเวลาพอสำหรับขั้นตอนการ Review โค้ดโดยเพื่อนในทีม

---

### 3. Continue (สิ่งที่ทำได้ดีและควรทำต่อไป)
* **มาประชุมตรงเวลา:** รักษาวินัยในการเข้าร่วมประชุมตรงตามเวลาที่นัดหมาย เพื่อความต่อเนื่องในการสื่อสารของทีม

---
